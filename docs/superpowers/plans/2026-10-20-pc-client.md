# PC 客户端（Electron 壳）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `app/` 下建立 pnpm workspace，新增 Electron 桌面壳包（复用现有 Web UI 与远端 API），并落地平台适配层与 API 网关两级扩展缝。

**Architecture:** 方案 A（轻量 workspace）。`frontend` 保持独立可构建；`desktop` 为 Electron 壳，主进程内置回环代理解决 `file://` 源的 CORS/SSE 问题；renderer 通过 preload 白名单桥访问桌面能力。设计详见 `docs/superpowers/specs/2026-10-20-pc-client-design.md`。

**Tech Stack:** pnpm 10.33.1 workspace、Electron、TypeScript（CJS，主进程）、vitest（主进程单测）。

## Global Constraints

- pnpm 版本固定 `10.33.1`（corepack 已 pin，Dockerfile 注释说明过原因：Node 20 corepack 默认新版 pnpm 要求 Node 22）
- 锁文件唯一：`app/pnpm-lock.yaml`（workspace 根），删除 `app/frontend/pnpm-lock.yaml`
- Web 端行为零变化：不改动任何 feature 代码；renderer 的 API base URL 仅在桌面 preload 注入时覆写
- Electron 安全基线：`contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`，preload 只暴露白名单
- 本迭代不实现：本地 Agent、SQLite、离线模式、打包分发（electron-builder）、Playwright 冒烟
- spec 与实现的一处签名偏差：`PlatformAdapter.info()` 返回 `Promise<PlatformInfo>`（IPC 是异步的），`PlatformInfo.platform` 类型为 `string`（Web 侧不能引用 `NodeJS.Platform`）
- 仓库无 `.github/workflows`，CI 追加桌面检查一项跳过

- [ ] **Step 4: 实现 electron/proxy.ts**

```ts
/**
 * @file Loopback API proxy
 *
 * The packaged renderer runs from a file:// origin, so direct API calls would
 * fail CORS preflight and complicate SSE. The renderer therefore talks to
 * http://127.0.0.1:<port>; this proxy forwards requests verbatim to the real
 * API and adds permissive CORS headers. It must not buffer response bodies —
 * Run event streams (SSE) flow through it.
 */
import http from 'node:http';
import type { AddressInfo } from 'node:net';

export interface ApiProxy {
  readonly baseUrl: string;
  close(): void;
}

/** Start a loopback proxy forwarding all requests to `target` (e.g. http://localhost:8000). */
export async function startApiProxy(target: string): Promise<ApiProxy> {
  const targetUrl = new URL(target);
  const server = http.createServer((req, res) => {
    if (req.method === 'OPTIONS') {
      res.writeHead(204, {
        'access-control-allow-origin': '*',
        'access-control-allow-methods': 'GET,POST,PUT,PATCH,DELETE,OPTIONS',
        'access-control-allow-headers': 'authorization,content-type,accept,last-event-id',
      });
      res.end();
      return;
    }
    const upstream = http.request(
      {
        hostname: targetUrl.hostname,
        port: targetUrl.port,
        path: req.url,
        method: req.method,
        headers: { ...req.headers, host: targetUrl.host },
      },
      (upstreamRes) => {
        res.writeHead(upstreamRes.statusCode ?? 502, {
          ...upstreamRes.headers,
          'access-control-allow-origin': '*',
        });
        upstreamRes.pipe(res);
      },
    );
    upstream.on('error', () => {
      if (!res.headersSent) res.writeHead(502);
      res.end();
    });
    req.pipe(upstream);
  });
  await new Promise<void>((resolve) => server.listen(0, '127.0.0.1', resolve));
  const { port } = server.address() as AddressInfo;
  return { baseUrl: `http://127.0.0.1:${port}`, close: () => server.close() };
}
```

- [ ] **Step 1: electron/main.ts**

```ts
/**
 * @file Electron main process
 *
 * Window lifecycle, window-control IPC, and the loopback API proxy. This
 * process is the future host of the local database and local agent runtime;
 * keep renderer-facing surface behind the preload whitelist only.
 */
import path from 'node:path';
import { app, BrowserWindow, ipcMain } from 'electron';
import { startApiProxy, type ApiProxy } from './proxy';

const DEV_SERVER_URL = process.env.VITE_DEV_SERVER_URL ?? 'http://localhost:3000';
const API_TARGET = process.env.LITE_ATOMS_API_TARGET ?? 'http://localhost:8000';

let proxy: ApiProxy | undefined;
let ipcRegistered = false;

/**
 * Register IPC handlers once for the app lifetime. Window commands resolve the
 * sender's window at dispatch time, so macOS dock re-activation (which creates
 * a fresh window) never double-registers or touches a destroyed window.
 */
function registerIpc(): void {
  if (ipcRegistered) return;
  ipcRegistered = true;
  ipcMain.on('window:minimize', (event) => {
    BrowserWindow.fromWebContents(event.sender)?.minimize();
  });
  ipcMain.on('window:maximize', (event) => {
    const win = BrowserWindow.fromWebContents(event.sender);
    if (!win) return;
    if (win.isMaximized()) win.unmaximize();
    else win.maximize();
  });
  ipcMain.on('window:close', (event) => {
    BrowserWindow.fromWebContents(event.sender)?.close();
  });
  ipcMain.handle('app:info', () => ({ appVersion: app.getVersion(), platform: process.platform }));
}

async function createWindow(): Promise<void> {
  proxy ??= await startApiProxy(API_TARGET);
  registerIpc();

  const win = new BrowserWindow({
    width: 1440,
    height: 900,
    webPreferences: {
      preload: path.join(__dirname, 'preload.js'),
      contextIsolation: true,
      nodeIntegration: false,
      sandbox: true,
      additionalArguments: [`--lite-atoms-api-base=${proxy.baseUrl}`],
    },
  });

  if (!app.isPackaged) {
    await win.loadURL(DEV_SERVER_URL);
  } else {
    await win.loadFile(path.join(__dirname, '../../../frontend/dist/index.html'));
  }
}

app.on('quit', () => proxy?.close());

void app.whenReady().then(createWindow);

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') app.quit();
});

app.on('activate', () => {
  if (BrowserWindow.getAllWindows().length === 0) void createWindow();
});
```

/**
 * @file Preload bridge
 *
 * The only surface between the sandboxed renderer and the main process.
 * Exposes the whitelisted `window.liteAtoms` API and the loopback API base
 * URL that the main process passes via additionalArguments (readable from
 * process.argv in sandboxed preloads).
 */
import { contextBridge, ipcRenderer } from 'electron';

const API_BASE_PREFIX = '--lite-atoms-api-base=';
const apiBaseArg = process.argv.find((arg) => arg.startsWith(API_BASE_PREFIX));
const apiBaseUrl = apiBaseArg ? apiBaseArg.slice(API_BASE_PREFIX.length) : undefined;

contextBridge.exposeInMainWorld('__LITE_ATOMS_API_BASE_URL__', apiBaseUrl);
contextBridge.exposeInMainWorld('liteAtoms', {
  window: {
    minimize: () => ipcRenderer.send('window:minimize'),
    maximize: () => ipcRenderer.send('window:maximize'),
    close: () => ipcRenderer.send('window:close'),
  },
  info: () => ipcRenderer.invoke('app:info'),
});
