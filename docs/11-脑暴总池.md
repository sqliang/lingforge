## 0. 使用说明

- **筛选方式**：在「选」列标记你的决定（✅ 入选 / 👀 观察 / ❌ 放弃），再告诉我，我据此更新总表并推进正式评估。
- **评分列**：痛=痛点强度，AI=AI 适配度，复=底座复用度，施=单人可实施性，技=技能成长（各 1–5）；合=合计（满分 25）。
- **量级**：S≲1 周，M≈1–2 周，L>2 周（单人估，弹性 ±50%）。
- **标记列**：★=该轮 shortlist；⚠=有特殊前置（架构议题/敏感数据/红线设计）。
- 排序视图见 §2，枢纽依赖视图见 §3，反建议汇总见 §5。

## 5. 反建议汇总（四轮合并，明确不做）

- 通用日历/邮箱/Todo 客户端；邮箱/日历/支付的 OAuth 深度集成（M4 为边界样本）
- 多人协作/家庭共享（D4 完整版）
- 反爬对抗型监控（电商比价爬虫、抢票、高频监控）
- 医疗/心理/法律/金融的诊断与建议（R 簇、K3、L3 均为「记录与观察」定位）
- 完整 Anki/间隔重复系统、完整 PPT/视频编辑器
- AI 全权代写代发（创作必须有人确认门；发布只做到「复制就绪」）
- 自动导入银行流水；文件自动删除（永不删除，删除权归用户）
- 密码/密钥管理（清单可存，凭据永不存）
- 视频生成/数字人/语音克隆；相册人脸识别；社交关系打分排名
- 移动 App/微信机器人入口（先把 Web 平台做成日常入口）
