# 功能脑暴 · 第二轮：创作与表达

> 版本：1.0（脑暴稿，待 review）
> 定位：继 [7-功能脑暴](./7-功能脑暴.md)（信息/知识/职业/生活事务/开发者日常）之后的第二轮，换一个全新视角：**AI 作为创作与表达伙伴**——内容创作、个人品牌、表达训练、记忆留存。与 docs/7 已覆盖的候选不重复；与 [6-综合平台升级评估方案](./6-综合平台升级评估方案.md) 的三功能主线和底座（Run/SSE/Artifact/GenUI/编辑器）保持衔接。
> 同样纪律：痛点优先、三维筛选（痛点真实 × AI 适配 × 底座复用）、候选≠承诺、不确定性诚实标注。

## 0. 本轮视角说明

docs/7 解决的是「输入侧」问题（信息过载、知识散落、事务没人记）。这一轮看「**输出侧**」：一个知识工作者想表达、想创作、想被看见，但卡在：

```text
输出侧痛点地图
─────────────────────────────────────────────────────────
W1 启动难：想写/想录/想发，但空白页恐惧症，选题纠结一周
W2 坚持难：内容日历做了就废，创作靠热情没有节奏
W3 改写烦：一篇内容要发公众号/博客/推特/小红书，每个平台
   都要重新排版改语气，机械劳动吃掉创作乐趣
W4 素材散：灵感、金句、截图、草稿散落在五六个 App 里，
   创作时想不起来自己攒过什么
W5 表达缺反馈：演讲/汇报/路演，讲完不知道好不好，
   没有人给语速、结构、口头禅的客观反馈
W6 回忆流失：照片/旅行/重要时刻拍完就沉底，
   年终想回顾时发现什么都没整理
─────────────────────────────────────────────────────────
横切痛点 Y：「素材 → 草稿 → 多形态成品 → 发布/归档」这条
   创作流水线，恰好是 Agent（生成+改写+格式化）的主场。
```

## 1. 候选功能池（11 个）

> 卡片格式同 docs/7：痛点 → 形态 → Agent 角色 → 底座关系 → 量级（S/M/L）→ 不确定性。

### 簇 G · 内容创作流水线（对应 W1/W2/W3）

**G1. 内容创作 Pipeline**
- 痛点：空白页恐惧 + 选题纠结（W1）。
- 形态：选题库（灵感随手记）→ 选中后 Agent 生成大纲 → 用户确认（复用审批门！）→ 分节生成草稿 → 富文本编辑器精修 → 存为文章 Artifact。
- Agent 角色：大纲生成 + 分节写作 + 风格保持（注入用户历史文风，见 G7）。
- 底座关系：与 DeepResearch 的报告流程**同构**（计划→确认→分节写→编辑器），几乎是现成骨架换 prompt；文章=report Artifact。
- 量级：M。不确定性：AI 味过重——必须设计「用户声音优先」的 prompt 策略（草稿=骨架+素材，不是代写）。

**G2. 演示稿/PPT Agent** ⭐
- 痛点：做 PPT 是高频工作痛点——内容有，排版分页耗半天。
- 形态：输入主题/文档 → Agent 生成分页大纲（每页标题+要点+演讲备注）→ 用户调整 → **GenUI 渲染为可演示的网页幻灯片**（方向键翻页）→ 导出 PDF/HTML。
- Agent 角色：内容结构化 + 分页设计；渲染是确定性 GenUI 模板。
- 底座关系：**GenUI 的新渲染形态**（Slide 组件族：标题页/要点页/图表页/对比页/金句页），是 GenUI 引擎继「对话卡片」后的第二个大场景；幻灯片=web Artifact。
- 量级：M。不确定性：不要追求 PowerPoint 级编辑自由度——定位「快速出能讲的稿」，复杂设计仍导出后人工做。

**G3. 个人内容日历**
- 痛点：创作无节奏（W2）。
- 形态：设定频率目标（如每周一篇）→ 选题库排期 → 到期前晨报提醒 → 完成后打卡，断更预警。
- Agent 角色：几乎不需要 AI——确定性排期 + 提醒；AI 只在「选题枯竭时基于知识库建议选题」。
- 底座关系：定时基建（docs/7 A1）+ 选题库=轻量实体 + 打卡=GenUI 卡片。
- 量级：S。不确定性：低；但价值依赖 G1 存在才有意义。

**G4. 多平台分发改写**
- 痛点：一文多发的机械改写（W3）。
- 形态：以文章 Artifact 为源 → 一键生成各平台版本（公众号排版版/推特线程/小红书短文案/LinkedIn 英文版）→ 每版可单独精修 → 导出清单。
- Agent 角色：平台风格改写（每个平台=一个风格 prompt 模板）。
- 底座关系：源=文章 Artifact；产物=多版本 Artifact（父子关联）；零新基建。
- 量级：S–M。不确定性：各平台 API 发布不做（违反「不做第三方业务集成」边界），只做到「复制就绪」。

**G5. 视频脚本与分镜**
- 痛点：想录视频/技术分享，脚本和分镜难产。
- 形态：主题 → 脚本（口播稿+分镜表：画面/台词/时长）→ 录制后生成字幕文件（SRT）→ 字幕校对编辑器。
- Agent 角色：脚本生成 + ASR 字幕（与 docs/7 B2 会议纪要共享 ASR 依赖）。
- 底座关系：脚本=report Artifact；字幕编辑器是新的轻量编辑形态（时间轴+文本）。
- 量级：L（ASR 依赖）。不确定性：与 B2 同为 L，建议合并评估「音频管线」基建。

### 簇 H · 表达训练与素材（对应 W4/W5）

**H1. 演讲/表达练习教练**
- 痛点：汇报/面试自我介绍/技术分享，讲完无客观反馈（W5）。
- 形态：录音/录像上传 → 转写+分析 → 反馈报告：语速曲线、口头禅计数（「然后」「就是」）、结构完整度（有无论点-论据-结论）、时间控制 → 历史对比曲线。
- Agent 角色：ASR + 结构化表达分析（语速/填充词=确定性计算，结构评价=LLM）。
- 底座关系：音频=media Artifact；报告=report Artifact；**与 docs/7 E1 面试教练是姊妹篇**（一个练内容，一个练表达），可共享音频管线。
- 量级：M–L。不确定性：录像分析（肢体语言）v1 不做，只做音频层。

**H2. 灵感/金句捕捉**
- 痛点：灵感随手记在各种地方，创作时找不到（W4）。
- 形态：统一速记入口（输入框/快捷指令）→ Agent 自动打标、关联相似笔记 → 创作时（G1 大纲阶段）自动召回相关灵感。
- Agent 角色：自动打标 + 语义关联（embedding）。
- 底座关系：笔记=轻量 Artifact，自动入 docs/7 C1 知识库；召回=RAG。
- 量级：S（C1 之后）。不确定性：低；本质是 C1 的「快速写入端」。

**H3. 写作风格画像**
- 痛点：AI 代写的东西「不像我」，自己也不知道「像我」是什么。
- 形态：导入历史文章 → 分析风格指纹（句长分布、词汇偏好、节奏、口头禅、常用比喻）→ 生成「风格卡」→ 注入 G1/G4 的所有生成 prompt。
- Agent 角色：文体统计分析 + 风格摘要。
- 底座关系：风格卡=配置型 Artifact；被创作管线全局引用。
- 量级：S–M。不确定性：风格迁移的上限有限——预期管理为「减少 AI 味」，不是「完美克隆」。

### 簇 J · 记忆留存与回顾（对应 W6）

**J1. 个人年报** ⭐
- 痛点：年终回顾时才发现一年没留下痕迹（W6）。
- 形态：年末汇聚全平台数据（Artifact 统计、研究过的主题、写过的文章、Coding 项目、晨报阅读偏好）+ 用户补录的生活事件 → 生成「个人年度报告」：数据图卡 + 主题时间线 + 高光时刻 → 精美 GenUI 长页，可分享（导出图片/PDF）。
- Agent 角色：数据聚合 + 叙事生成；图卡=GenUI Chart 组件（新技能点：数据可视化）。
- 底座关系：**全平台 Artifact 体系的年度大秀**——它是 Artifact 中心价值的终极证明。
- 量级：M。不确定性：数据稀疏的年份效果打折；定位为「平台使用者的彩蛋」，不是拉新功能。

**J2. 相册整理与回忆**
- 痛点：几千张照片从未整理（W6）。
- 形态：批量导入 → 去重/按时间地点聚类/挑出走失焦废片 → 自动生成「XX 之旅」「2026 夏天」主题相册 → 可配文字生成旅行记忆册。
- Agent 角色：图片理解（多模态：内容描述、质量评分）+ 聚类（确定性）。
- 底座关系：图片=image Artifact（docs/6 §8.1 图片查看器的用武之地）；相册=组合型 Artifact。
- 量级：L（大批量图片处理成本）。不确定性：照片是隐私重地——处理策略与存储成本需专项评估；列为观察项。

**J3. 日记/晨间笔记复盘**
- 痛点：写日记坚持难，写了也从不回看。
- 形态：每日几句话速记（输入框即写）→ 每周 Agent 复盘：主题趋势、情绪走向、反复出现的烦恼 → 周报卡片进晨报 → 「一个月前的今天在烦恼什么」回顾。
- Agent 角色：情绪/主题分析（脱敏摘要，不存原始日记全文给模型）。
- 底座关系：日记=私密 Artifact（加密/特殊保留策略）；复盘走定时基建+晨报通道。
- 量级：M。不确定性：**情绪数据极其敏感**——需要明确的隐私设计与「不做心理建议」红线（呼应 J 簇反建议）。

## 3. 推荐 Shortlist（3 个）

1. **G2 演示稿 Agent（21 分）**：工作最高频的创作痛点；「GenUI 渲染网页幻灯片」是 GenUI 引擎继对话卡片后的第二个杀手场景——比聊天卡片更能展示 GenUI 的想象力（可演示、可分享、可导出）。注意边界：做「能讲的稿」，不做 PPT 编辑器。
2. **G1+G4 创作管线与分发改写（19+19，合并为一个项目）**：与 DeepResearch 报告流程同构，边际成本最低的完整创作闭环；G4 依附 G1 存在，单独做无源之水。
3. **J1 个人年报（20 分）**：不解决高频痛点，但它是 Artifact 体系的「价值放大器」和用户情感锚点——且数据可视化（Chart 组件）是新技能点。适合作为平台里程碑节点的彩蛋项目。

观察项：H1 演讲教练（等音频管线与 E1 面试教练一起评估）、J3 日记复盘（隐私设计先行）、J2 相册整理（成本与隐私，暂缓）。

## 4. 与前轮的协同

```text
G1 创作管线 ──吃── docs/7 C1 知识库（素材召回）+ H3 风格卡
G2 演示稿  ──吃── DeepResearch 报告（研究成果 → 演示稿，一键转化）
J1 年报    ──吃── 全平台 Artifact（数据源头越多越精彩）
H1 演讲教练 ──共享── docs/7 E1 面试教练的音频管线 + 评分体系
J3 日记复盘 ──复用── docs/7 A1 晨报通道 + 定时基建
```

本轮候选再次验证 docs/7 §5 的判断：**枢纽节点（知识库、定时、Artifact）越扎实，新场景的边际成本越低**。G1/G4/J1 都是「零新基建」候选。

## 5. 反建议（本轮）

| 方向 | 为什么不 |
| --- | --- |
| 完整 PPT/视频编辑器 | 巨头与专业工具战场；做「生成+轻编辑」，不做「编辑器」 |
| 自动发布到各平台（API 对接） | 违反「不做第三方业务集成」边界，账号授权是安全泥潭；只做到「复制就绪」 |
| AI 代写全权自动化（无人确认） | 产出「AI 味」内容损害个人品牌；审批门/人确认是创作管线的不可省环节 |
| 视频/录像的肢体语言分析 | 准确率与成本不成比例，音频层反馈已覆盖 80% 价值 |
| 心理/情绪建议（J3 延伸） | 红线：只做「记录与模式观察」，明确不做心理干预建议 |
| 相册人脸识别与社交图谱 | 隐私风险远超价值，不做 |
